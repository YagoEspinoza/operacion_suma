# 🧮 Script de Suma con Validación de Tipos en Python

Este proyecto contiene un script en Python que realiza la **suma de dos números** (ya sean enteros o decimales) con **validación de los operandos** para asegurar que sean del tipo `int` o `float`.

## 📌 Descripción

El objetivo del script es recibir dos valores, verificar que sean numéricos (`int` o `float`), y retornar su suma. Si alguno de los valores no cumple con el tipo esperado, el script mostrará un mensaje de error amigable.

## ✅ Funcionalidades

- Entrada de datos desde la consola.
- Conversión y validación de tipo (`int` o `float`).
- Suma y presentación del resultado.
- Manejo de errores para entradas no numéricas.
